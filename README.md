An original short poem, "The Night the River Rose", about the power of
stopping: restraint, waiting, and the choice not to act.

Built for [make.fun](https://make.fun/bounty/the-poem-about-stopping-20261121-1927)'s "The poem about stopping" bounty.

## Run

```sh
python3 main.py
```

The poem is written to `/output/entry.txt`. The program uses only the
Python standard library, works offline, and is deterministic: running it
twice produces byte-identical output.
